# Hugging Face · Apuntes y prácticas (CE IA&BD)

Materiales docentes sobre el **ecosistema Hugging Face** (Transformers, Datasets, Hub, Tokenizers, pipelines y fine-tuning) para el Curso de Especialización en Inteligencia Artificial y Big Data (Grado E), Comunitat Valenciana, curso 2026-2027.

Profesor: José Manuel Pérez Torres · Centro: I.E.S. Severo Ochoa (Elche).

Generado con MkDocs (tema Material). Solo web + notebooks de Jupyter.

## Alcance (multimódulo)

Hugging Face es una herramienta transversal que se imparte en **dos módulos**:

| Módulo | Código | RA que toca Hugging Face |
|--------|--------|---------------------------|
| Modelos de Inteligencia Artificial (MIA) | 5071 | RA1 (caracterización), RA2 (modelos), RA5 (sistemas expertos/guardarraíles) |
| Programación de Inteligencia Artificial (PIA) | 5072 | RA3 (procesamiento de lenguaje natural) |

## Estructura

- `PLAN.md` — plan maestro por sesiones de 2h.
- `AGENTS.md` — estado, decisiones y convenciones.
- `FUENTES.md` — fichas de normativa y referencias técnicas.
- `curriculo.yml` — datos curriculares (RA/CE, calendario, pesos) en la raíz.
- `docs/` — web (`index`, `bloques/MIA_*` y `bloques/PIA_*`, `evaluacion/`).
- `legislacion/` — plantilla de sesión.
- `practicas/` — notebooks `.ipynb` por sesión/bloque.

## Cómo se organiza

Cada bloque se alinea con un RA de un módulo. Dentro de cada bloque, las sesiones de 2 h (lunes y miércoles) siguen `legislacion/plantilla_sesion.md`, con apuntes, práctica guiada (solución) y miniproyecto (notebook `.ipynb` renderizado con botones *Abrir en Colab* / *Descargar*).
