# Hugging Face · Curso práctico (CE IA&BD)

Materiales docentes de un **curso práctico de 14 h (7 sesiones × 2 h)** sobre el ecosistema **Hugging Face**, centrado en **usar y adaptar modelos preentrenados** (no en construir redes desde cero).

Profesor: José Manuel Pérez Torres · Centro: I.E.S. Severo Ochoa (Elche) · Curso 2026-2027.

Se imparte en paralelo a **Machine Learning** (Manuel Quinto) y **Deep Learning**, sin repetir sus contenidos.

Generado con MkDocs (tema Material). Solo web + notebooks de Jupyter.

## Estructura

- `PLAN.md` — plan maestro y decisiones.
- `AGENTS.md` — estado, convenciones y pendientes.
- `GUIA.md` — guía de referencia del compañero (Manuel Quinto), base del diseño.
- `curriculo.yml` — datos curriculares (RA/CE, calendario, evaluación).
- `docs/sesiones/` — 7 sesiones (guía de clase `.md` + notebook `.ipynb`).
- `docs/evaluacion/` — retos semanales y proyecto final (Space).
- `docs/relacion_ra.md` — mapa sesión → Resultados de Aprendizaje.

## Sesiones

1. Ecosistema y pipelines · 2. Tokenizadores · 3. Transformers por dentro · 4. Datasets y fine-tuning · 5. LLMs (generación, cuantización, LoRA) · 6. Visión, audio y multimodal · 7. Despliegue (Hub, Gradio, Spaces).

## Evaluación

Retos semanales (40 %) + Space final (60 %). Pendiente de reconciliar con la Orden 8/2025 (evaluación oficial del CE).
