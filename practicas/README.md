# practicas/

Notebooks `.ipynb` por sesión y bloque. Estructura sugerida:

```
practicas/
├── MIA_RA1/
├── MIA_RA2/
├── MIA_RA5/
└── PIA_RA3/
```

Cada sesión enlaza su notebook desde `docs/bloques/<MODULO>_<RA>/sesionNN_<tema>.md`. Los cuadernos también pueden servirse directamente desde `docs/bloques/.../` (como en `mia`) si se prefiere que mkdocs-jupyter los renderice en la web.
